# BEFOR9

**Be ready before 9.**

BEFOR9 is a bilingual Arabic/English early-stage platform concept for university students and recent graduates preparing for their first job.

## Current version
- Responsive introductory landing page
- Arabic/English language switcher
- Three introductory learning paths: professional communication, first week at work, everyday workplace skills
- No login, payment, or course backend yet

## Run locally
Open `index.html` in a browser. No build tools or dependencies required.

## Files
- `index.html`: page structure and content
- `styles.css`: responsive styling
- `script.js`: language switching

## Roadmap
1. Validate learning topics with students and recent graduates.
2. Create first short lesson with a practical exercise.
3. Add accessible course pages and progress tracking.
4. Add registration only when there is a clear need.

## Domain
Planned domain: befor9.com. Domain deployment is not configured by this repository.
